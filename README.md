# issue-management-system

A simple web-based Issue Management System developed using HTML, CSS, JavaScript, Node.js, Express.js, and MySQL.

The system allows clients to submit issues, administrators to manage and assign issues, and users to view and complete their assigned issues. It also provides a simple user-to-admin query system.

---

## 🚀 Live Application

https://issue-management-system-4hfb.onrender.com/


## 📌 Features

### 👤 Client

- Submit a new issue
- Select issue category
- Add issue title and description
- Provide issue location
- Submit issues without login

### 👨‍💼 Admin

- Admin login
- View all submitted issues
- View issue details
- Assign issues to users
- Track issue status
- View user queries
- Answer user queries

### 👷 User

- User login
- View only assigned issues
- View issue details
- Mark assigned issues as completed
- Submit queries to the admin
- View their own queries and admin responses

---

## 👥 User Roles

| Role | Access |
|------|--------|
| Client | Submit issues |
| Admin | Manage, assign, and track all issues |
| User | View and complete assigned issues |
